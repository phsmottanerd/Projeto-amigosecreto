# 🕵️‍♂️ **Amigo Secreto - Programa ONE ORACLE + ALURA**

### 🎮 Descrição do Projeto

Este projeto faz parte do **Programa ONE ORACLE + ALURA** e foi desenvolvido para permitir que os usuários participem de um jogo de **Amigo Secreto** de forma online e divertida! 

A aplicação permite que os participantes adicionem seus nomes, sorteiem seus amigos secretos e visualizem o resultado do sorteio em tempo real. Tudo de maneira simples e intuitiva, com foco na experiência do usuário.

**Funcionalidades:**
- ✏️ **Adicionar amigos**: Insira os nomes dos participantes.
- 🔮 **Sortear amigo secreto**: Realize o sorteio de forma automática e justa.
- 📜 **Exibir o resultado**: Veja quem tirou quem de maneira clara.
