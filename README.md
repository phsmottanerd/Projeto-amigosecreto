Jogo Amigo Secreto
Bem-vindo ao Jogo Amigo Secreto! Este é um projeto desenvolvido para a plataforma Alura, com o objetivo de criar uma aplicação interativa de Amigo Secreto utilizando as tecnologias HTML, CSS e JavaScript.

Descrição
O Jogo Amigo Secreto permite aos usuários digitar o nome de seus amigos, adicionar esses nomes à lista e, por fim, realizar o sorteio de forma aleatória para revelar quem é o amigo secreto de quem. A interface é simples e agradável, projetada para ser fácil de usar. O projeto foi desenvolvido de forma totalmente front-end, sem a necessidade de backend.

Tecnologias Utilizadas
HTML5: Utilizado para estruturar o conteúdo da página.
CSS3: Para o design e layout da página, incluindo responsividade e animações simples.
JavaScript: Para implementar a lógica de sorteio dos amigos secretos, manipulando os eventos do usuário.
Como Funciona
Adicione os Amigos: O usuário pode adicionar os nomes dos amigos na lista, clicando no botão "Adicionar".
Sortear: Após adicionar pelo menos dois amigos, o usuário pode clicar no botão "Sortear" para realizar o sorteio.
Exibição dos Resultados: O resultado será exibido abaixo da lista de amigos, mostrando quem tirou quem no sorteio.
